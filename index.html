법조문쌤 개인정보처리방침

시행일: 2026년 10월 24일 운영자: Brainy2357 연락처: brainy2357@gmail.com 1. 서비스와 개인정보 처리 법조문쌤은 법령·판례·법령용어 검색, 법조문쌤 및 관련 공식 채널의 YouTube 영상 재생, 국회 의안·표결 조회를 제공합니다. 앱 회원가입을 요구하지 않으며 운영자 서버에 이용자 계정·검색 이력을 수집·저장하지 않습니다. 광고 SDK, 분석 SDK, 위치·연락처·사진 수집 기능이 없습니다. 본 버전은 AI 법률상담 질문·답변을 처리하거나 AI 모델 API로 전송하지 않습니다. 2. 외부 서비스로 전송되는 정보 법령·판례·용어 검색어, 조회 조건과 문서 식별자는 국가법령정보센터에 HTTPS로 전송됩니다. 영상 목록·검색 시 채널 식별자·검색어·페이지 토큰·앱 패키지·서명 인증서 정보가 Google YouTube API에 전달됩니다. 영상 재생 시 내부 YouTube 플레이어가 Google/YouTube에 접속하며 IP·기기·브라우저 정보, 쿠키·재생 정보 등이 해당 정책에 따라 처리될 수 있습니다. 이름·주민번호 등 민감한 개인정보를 검색어에 입력하지 마세요. 3. 이메일 문의 문의 버튼은 기기의 이메일 앱을 실행합니다. 이용자가 자발적으로 보내는 이메일 주소·문의 내용·첨부는 응대와 오류 처리에 사용하며 처리 완료 후 1년 이내 삭제합니다. 법령상 보존 의무가 있으면 해당 기간 동안 보관합니다. 인증키·비밀번호·민감한 개인정보는 보내지 마세요. 4. 기기에 저장되는 정보와 국회 API 키 사용자가 입력한 열린국회정보 인증키는 Android Keystore의 암호화 키로 암호화해 앱 전용 저장소에 보관합니다. 키는 국회 API 조회를 위해 open.assembly.go.kr로만 HTTPS 전송하며 운영자 서버로 전송하지 않습니다. 국회 대수·의안명·의안 ID·페이지 조건도 해당 API로 전달됩니다. 국회 메뉴의 API 인증키 변경·삭제, 앱 데이터 삭제 또는 앱 제거로 저장 데이터를 지울 수 있습니다. 검색 결과는 실행 중 메모리에서 처리하며 홈 복귀 시 법령·판례·용어 본문을 해제합니다. YouTube 목록은 재조회 비용을 줄이기 위해 실행 중 메모리에 남을 수 있습니다. YouTube WebView는 동작 과정에서 쿠키·캐시를 저장할 수 있고 Android 앱 데이터 삭제로 제거할 수 있습니다. 백업은 사용하지 않습니다. 5. 외부 서비스 정책 제공기관은 요청 처리·보안 등을 위해 접속 로그·IP·기기 정보를 각 정책에 따라 처리할 수 있습니다. 앱이 별도 저장하지 않는다는 안내가 외부 서비스의 로그 미처리를 의미하지는 않습니다. 공식 원문 링크를 열면 해당 기관의 정책이 적용됩니다. 국가법령정보센터: https://www.law.go.kr YouTube: https://www.youtube.com Google 개인정보처리방침: https://policies.google.com/privacy 열린국회정보: https://open.assembly.go.kr 6. 권리 행사와 방침 변경 개인정보 관련 문의·열람·정정·삭제 요청은 brainy2357@gmail.com으로 접수해 주세요. 외부 서비스가 보관하는 정보는 해당 서비스의 권리 행사 절차가 필요할 수 있습니다. 방침 변경은 앱의 도움말 및 문의에서 안내합니다.
